# Corporate · веб-кабинеты

Десктоп для **HR компании**, **мерчанта** и **админа**. Сотрудникам сайт не нужен — они в Android.

Вход обычный: email + пароль. Сверху временные демо-кнопки — подставляют поля и логинят теми же данными. Потом кнопки уберём.

## Запуск

```bash
cd web
npm install
npm run dev
```

http://localhost:5173

В сайдбаре HR / мерчанта / админа есть **Lin**. Сотрудникам веб-чата нет.

## Локальная модель (Ollama, бесплатно)

Без ключей. Сначала поднимаете Ollama, потом сайт. Если Ollama не запущена, ассистент всё равно отвечает по данным кабинета.

```bash
# https://ollama.com — установка
ollama pull qwen2.5:1.5b
ollama serve
```

В другом терминале: `npm run dev`. Запросы идут на `/ollama` → `127.0.0.1:11434`. Сначала `qwen2.5:1.5b`, затем `llama3.2:1b`, `qwen2.5:0.5b`, `phi3`. Таймаут ~20 с — дальше ответ из данных.
