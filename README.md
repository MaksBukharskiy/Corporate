# Corporate

Платформа корпоративных льгот.

## Структура

```
corporate/
├── mobile/   Android для сотрудника, мерчанта, админа
└── web/      десктоп для HR, мерчанта и оператора платформы
```

## Web

```bash
cd web
npm install
npm run dev
```

Демо-вход: клик по карточке роли. Сотрудникам сайт не нужен.

## Mobile

Открыть `mobile/` в Android Studio и запустить на эмуляторе.
