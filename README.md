# Corporate

Платформа корпоративных льгот.

## Структура

```
corporate/
├── mobile/   Android-приложение (Jetpack Compose)
└── web/      (пусто)
```

## Mobile

Открыть `mobile/` в Android Studio и запустить на эмуляторе.

На старте три роли без пароля: сотрудник, мерчант, админ. Данные в памяти процесса.
